LRC ⇄ SRT Studio

Chuyển đổi, chỉnh sửa và đồng bộ phụ đề ngay trên trình duyệt.

1. Nhập nội dung

Kéo thả file .lrc / .srt / .txt vào đây
Ô nhập / dán văn bản0 ký tự
Bạn có thể dán nội dung hoặc chọn file.

2. Tùy chỉnh chuyển đổi

Mẹo đồng bộ: nếu lời hiện chậm hơn nhạc 0,8 giây, nhập -800. Nếu lời hiện sớm hơn nhạc 0,8 giây, nhập 800.
Tiện ích thêm: với SRT, bạn có thể dán nội dung vào ô bên trái, phân tích, chỉnh văn bản ở ô kết quả rồi xuất file. Thời gian SRT được giữ nguyên nếu không chỉnh offset.

3. Kết quả SRT (có thể chỉnh sửa)

Nội dung xuất0 ký tự

4. Chuyển đổi hàng loạt

Khi bạn chọn nhiều file ở phần trên, mỗi file sẽ được xử lý riêng. Sau khi chuyển đổi, tải từng file hoặc tải tất cả thành một gói ZIP (nếu trình duyệt hỗ trợ tạo ZIP tại chỗ).

Chưa có kết quả hàng loạt.
Riêng tư: mọi thao tác chạy trên thiết bị của bạn, không tải nội dung lên máy chủ. Nếu cần gói ZIP, bạn có thể tải từng SRT; trang này không dùng thư viện ZIP bên ngoài.
